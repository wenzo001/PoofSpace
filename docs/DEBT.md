# 欠账台账（每条都可被证伪）

规范里的句子与"实际做到并有判据"之间还差什么。每一栏都写了**用什么读数推翻这一栏的前提**，
所以它不是一段免责声明，而是一张待办 + 一条能跑出来的判据。
状态：`OPEN` = 未做；`PARTIAL` = 做了但覆盖不到主张的全部；`CLOSED` = 有判据且本轮绿。

| D20 | "浏览器线那 30 秒建房预算不会偶发不够"（一次未复现的间歇红） | 开源发布那一轮的第一次整台面：**13 PASS / 3 FAIL**，三条红（B6、B10、T5）**全部来自同一条腿** —— `https lock tooltip` 在 TLS 节点上 `createRoom` 时 `page.waitForSelector: Timeout 30000ms exceeded`。单跑该腿绿、独立整跑浏览器线两遍绿（10 条腿）、同一个包重跑台面 **16 PASS**（`gates-oss-final.log` vs `gates-oss-final2.log`） | OPEN | 这是一条**只见过一次**的间歇红，没有被第二次绿抹掉。要结案需要下面任一个读数：①再现一次并把那一刻的服务端日志/`page.on('requestfailed')` 打出来（看是 TLS 首请求慢、Next 冷启动慢，还是 `create` 真被拒）；②把预算改成"上界计数"而不是墙上时钟（例如断言 30 s 内 `POST /api/rooms` 的**响应已到达**并打出状态码，红时能直接说是 5xx 还是没答）。**禁止**用调大 timeout 把它消音 —— 那只会让下一次更长的卡顿继续沉默（见 [[latency-gate-cannot-catch-2x]]、[[reflake-classify-by-signature]]） |

## 用法

- 每条欠账**修掉之后不许直接撤账**：先把它对应的判据（或反向证人）落到门禁里、跑出绿，再把那一行改成 `CLOSED` 并写明判据名。
- 新增主张时先在这一张表里找它的格子；找不到就说明这条主张目前没有判据，那就是 OPEN。
